# 🌌 NOCTHAR DESKTOP

**A complete customization ecosystem for Linux Mint MATE.** (Um ecossistema completo de personalização para Linux Mint MATE).

## 📖 Sobre
O NOCTHAR DESKTOP é uma suíte modular e segura para transformar seu Linux Mint MATE em um ambiente digital sofisticado, sombrio e tecnológico. Baseado na estética Cyber-Gothic, Darkwave e Frutiger Aero Sombrio.

## ✨ Features
- 🎨 **3 Perfis Visuais:** Core (Minimalista), Abyss (Gothic), Nexus (Cyberpunk).
- 🔄 **Rollback Transacional:** Se algo falhar, o sistema volta ao estado anterior automaticamente.
- 🖥️ **Interface Gráfica (GTK3):** Painel de controle visual em Python.
- 📦 **Instalação Segura:** Tudo é instalado no escopo do usuário, sem quebrar o sistema.
- 🖼️ **Wallpaper Engine:** Gera wallpapers exclusivos em SVG na hora.

## 🚀 Instalação

git clone https://github.com/aquelejoaovittor/nocthar-desktop.git
cd nocthar-desktop
chmod +x install.sh
./install.sh

Após instalar, procure por **NOCTHAR DESKTOP** no menu de aplicativos ou rode `./launcher.sh` no terminal.

## 🛠️ Tecnologias
- Bash (Backend e Automação)
- Python 3 + PyGObject (Interface Gráfica)
- dconf / gsettings (Configurações MATE)
- jq (Processamento JSON)
